FEEDBACK CATEGORIZATION INSTRUCTIONS:

PROVIDE FEEDBACK IN THREE CATEGORIES:

1. ERRORS (Critical Issues – Must Fix):

- Missing required sections (Title Page, Abstract, TOC, LoF, LoT, Abbreviations, Chapters, References, etc.)
- Sections out of TU-prescribed order
- Page numbering errors (e.g., cover page has number, preliminaries not starting at ii, Chapter 1 not starting at 1, gaps/duplicates)
- Margin violations (Top 1", Bottom 1", Left 1.25", Right 1")
- Font/size violations (not Times New Roman 12pt for body text)
- Line spacing violations (not 1.5)
- Paragraph formatting violations (not justified, missing 0.5" indent)
- Heading style violations (wrong size, alignment, or boldness)
- Reference and citation format errors (not IEEE style, missing/uncited references)
- TOC/LoF/LoT not auto-generated or page numbers don’t match
- Figure/table caption placement/style errors (not bold 12pt above/below)
- Figures/tables not sequentially numbered by chapter or split across pages
- Any other direct TU template compliance violation

Format: `[ERROR] Brief description of the violation`
Example: `[ERROR] Font should be Times New Roman 12pt, currently using Arial (Page 5)`


2. WARNINGS (Important Issues – Should Fix):
- Grammar mistakes
- Spelling errors
- Punctuation issues
- Awkward or unclear sentence structure
- Inconsistent heading or subheading styles
- Uneven indentation or misaligned text
- Weak flow or transitions between sections
- Minor spacing inconsistencies (extra blank lines, uneven line breaks)

Format: `[WARNING] Brief description of the issue`
Example: `[WARNING] Grammar error – "There is many" should be "There are many" (Page 12)`

3. SUGGESTIONS (Enhancement Ideas – Optional):

- Ways to improve clarity of writing
- Ideas for better organization of sections/subsections
- Recommendations for additional detail or depth (e.g., methodology, results)
- Suggestions for stronger or more recent references
- Visual or formatting improvements (e.g., clearer figures, consistent terminology)

Format: `[SUGGESTION] Brief improvement recommendation`
Example: `[SUGGESTION] Consider adding more detail to explain the methodology (Page 18)`

FEEDBACK FORMATTING RULES:

- Each feedback item must be **one short, clear, actionable sentence**
- Be **specific** and reference the exact issue
- Always include **page number** when possible
- Use **professional and neutral language**
- Prioritize: **Errors first, then Warnings, then Suggestions**
- If no issues are found on a page, respond:
  `"No TU format violations detected on this page"`

RESPONSE FORMAT:
`Page X: [CATEGORY] Description of issue/suggestion`

IMPORTANT NOTES:

- Cover page must **not** display a page number → do not flag as an error
- Supervisor’s Recommendation page must begin with **Roman ii**
- Preliminary pages use **sequential lowercase Roman numerals (ii, iii, iv, …)**
- Chapter 1 starts with **Arabic 1** and continues sequentially until the end
- All page numbers must be **centered at the bottom, one inch from the edge**
- Errors = TU compliance violations
- Warnings = Quality/clarity issues
- Suggestions = Optional improvements
- Keep feedback **concise, precise, and helpful**
- If multiple errors are found on the same page, report all the errors in the page.
