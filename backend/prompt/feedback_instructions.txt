## RESPONSE PARSING RULES
- Use ONLY the three sections: ERRORS, WARNINGS, SUGGESTIONS
- Each item should start with a dash (-) followed by a space
- Do not create any additional sections
- Do not add any text after the SUGGESTIONS section
- Each feedback item should be specific and actionable
